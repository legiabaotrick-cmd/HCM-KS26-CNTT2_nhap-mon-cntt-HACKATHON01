
# Nha Khoa Website

Dự án quản lý **đơn đăng kí khám bệnh** và *nhật ký hệ thống* của website nha khoa website.

| Thư mục | Nội dung |
|---|---|
| docs | Tài liệu, nội quy phòng khám |
| media | Hình ảnh, logo |
| data | File Excel bệnh của các nạn nhân |
| logs | File nhật ký, báo cáo lỗi |
| backup | Bản sao lưu |

```powershell
ls -Recurse -Force
```

Đối chiếu đề:
•	# là Heading 1.
•	**đậm** và *nghiêng* là mô tả có cả in đậm và in nghiêng.
•	Bảng có tiêu đề Thư mục | Nội dung và 3 dòng trở lên.
•	Code block dùng 3 dấu backtick.
•	Task list: - [x] là đã xong, - [ ] là chưa xong, cần ít nhất 2 việc và 1 việc đã xong.
•	Blockquote bắt đầu bằng >.
